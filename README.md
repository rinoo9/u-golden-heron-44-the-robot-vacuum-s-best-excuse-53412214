# The Robot Vacuum's Best Excuse

A one-line robot vacuum excuse entry for the make.fun bounty "The Robot Vacuum's Best Excuse". The program `main.py` writes a single excuse to `/output/entry.txt` — the vacuum skipped a spot out of respect for the dust bunny's squatter's rights.

> I did not miss that spot — I was respecting the dust bunny's squatter's rights. It has lived there longer than you have.

Run it with `python3 main.py`. It asserts the entry is 1–140 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
