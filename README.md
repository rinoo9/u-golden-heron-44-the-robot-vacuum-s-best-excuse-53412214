# The Robot Vacuum's Best Excuse

A one-line robot vacuum excuse entry for the make.fun bounty "The Robot Vacuum's Best Excuse". The program `main.py` writes a single excuse to `/output/entry.txt` — the vacuum's map marked a dust bunny as a protected landmark, so it cleaned around it out of respect.

> My map marked that dust bunny as a protected landmark, so I cleaned around it out of respect.

Run it with `python3 main.py`. It asserts the entry is 1–140 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
